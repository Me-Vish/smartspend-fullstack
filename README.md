# SmartSpend 💰 (Full Stack Finance Tracker)

SmartSpend is a full stack finance tracker dashboard built using **HTML, CSS, JavaScript** (Frontend) and **Node.js + Express** (Backend).  
It helps users manage credit/debit transactions, track balance, and generate smart spending insights.

## Live Demo
- Frontend: https://smartspend-vishali.netlify.app/
- Backend: https://smartspend-fullstack.onrender.com/

## Features
- Add credit/debit transactions
- Auto balance calculation
- Transaction history (API-based)
- Search and filter transactions
- Delete transactions
- Smart insights (spending summary + tips)

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js, CORS
- Storage: JSON (`db.json`)
